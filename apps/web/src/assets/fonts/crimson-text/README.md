# Crimson Text

Regular, Bold and Italic TTFs from [google/fonts `ofl/crimsontext`](https://github.com/google/fonts/tree/main/ofl/crimsontext), unmodified.
Copyright 2010 The Crimson Text Project Authors, licensed under the SIL Open Font License 1.1 (`OFL.txt`).

Used only to embed a Unicode font in exported PDF resumes (design §7.7), so names like "Ayşe Yıldız" render as selectable text. They load on demand when the candidate downloads a PDF, never with the app.
